# Logo de Dash

Una D hecha de cuadros y el cursor del Shell detrás: `D_`.

| Fichero | Para qué |
|---|---|
| `dash.svg` | El logo con su cuadro azul. Es el original. |
| `dash-16.png` … `dash-512.png` | El mismo, ya pasado a PNG. |
| `dash-sin-fondo.svg`, `dash-sin-fondo-500.png` | Sin el cuadro, para fondos propios. Aquí el guion va en azul. |

Está dibujado sobre una rejilla de 16×16. Cada cuadro cae en un píxel entero a 16, 32,
64, 128… px, y por eso se ve nítido a cualquiera de esos tamaños. Si lo amplías, hazlo en
múltiplos de 16.

Colores, los del Workbench:

- Azul `#0055AA`
- Naranja `#FF8800`
- Blanco `#FFFFFF`
