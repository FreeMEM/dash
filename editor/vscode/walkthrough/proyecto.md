# Un proyecto nuevo

**Dash: Nuevo proyecto** crea una carpeta con:

- `nombre.dash`: el programa, que abre la ventana y responde a sus botones;
- `ventana.dashui`: la ventana, para el editor visual;
- `.vscode/launch.json`: F5 lo depura en el Amiga emulado (y otra configuración para un Amiga real).
